# Mini Agent Runtime

> **Build First, Pi Next · Python · Agent Runtime Architecture Research**\
> 先跟随 learn-claude-code，用真实模型亲手搭建 Agent；再以 [Pi](https://github.com/earendil-works/pi) 为成熟设计参考逐步改造，最终形成自己的 Python Agent 内核，用于开发不同用途的 Agent。

**项目定位：技术研究与学习仓库，不是持续堆功能的 AI 产品。**

以动手理解为主，每次围绕一个机制讲解、实现和验证，按实际需要演进，避免提前搭建完整框架。
